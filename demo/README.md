## سیستم مورد نیاز

### محیط مورد نیاز
- **وردپرس**: 6.5+
- **PHP**: 8.1+ (با اکستنشن `sodium`)
- **MySQL**: 5.7+ / MariaDB 10.3+
- **اینترنت**: اتصال به APIs خارجی

### انتخاب دامنه
این دمو با یک دامنه محلی راه‌اندازی می‌شود. برای یک دمو واقعی، نیاز به:

1. **هاستینگ**: هر سرور میزبانی که از PHP 8.1+ پشتیبانی می‌کند
2. **دامنه**: دامنه اختصاصی (مثلا: `demo.yourdomain.com`)
3. **آدرس وردپرس**: هر آدرس subdirectory یا اصلی

### فایل‌های مورد نیاز

برای راه‌اندازی دمو، نیاز به:

1. **فایل‌های افزونه**: از فایل زیپ `enzo-telegram-ai-admin-1.0.0.zip` استفاده کنید
2. **وردپرس**: نسخه 6.5+ نصب شده
3. **MySQL**: پایگاه داده خالی
4. **رمزنگاری**: کلید `ENZO_ENCRYPTION_KEY` در `wp-config.php`

### مراحل نصب دمو

#### 1. دانلود
فایل زیپ را از مخزن دانلود کنید:
```bash
git clone https://github.com/enzo-wp/enzo-telegram-ai-admin.git
cd enzo-telegram-ai-admin
docker-compose up -d  # اگر از Docker استفاده می‌کنید
```

#### 2. آپلود به سرور
```bash
# آپلود فایل زیپ به سرور SCP
scp enzo-telegram-ai-admin-1.0.0.zip user@your-server:/var/www/
cd /var/www/
unzip enzo-telegram-ai-admin-1.0.0.zip
```

#### 3. نصب در وردپرس
```bash
# آپلود پوشه به wp-content/plugins
cp -r enzo-telegram-ai-admin wp-content/plugins/
# فعال‌سازی در صفحه افزونه‌ها
```

#### 4. پیکرپندی اولیه
1. **wp-config.php** را باز کنید و کلید رمزنگاری را اضافه کنید:
```php
define('ENZO_ENCRYPTION_KEY', 'رشته-تصادفی-حداقل-۳۲-کاراکتری');
```

2. **wp-config.php** را ویرایش کنید و تنظیمات پایگاه داده را اضافه کنید:
```php
define('DB_NAME', 'نام_پایگاه_داده');
define('DB_USER', 'نام_کاربر');
define('DB_PASSWORD', 'رمز_عبور');
define('DB_HOST', 'localhost');
```

3. **wp-config.php** را ذخیره کنید و اتصال به پایگاه داده را برقرار کنید.

#### 5. راه‌اندازی افزونه
1. پیشخوان وردپرس را باز کنید
2. از منوی «ENZO: AI Admin» وارد شوید
3. روی دکمه «شروع راه‌اندازی» کلیک کنید
4. مراحل راه‌اندازی را دنبال کنید:
   - انتخاب پلتفرم (تلگرام، بله، ایتا یا روبیکا)
   - اتصال ربات (Bot Token)
   - اتصال به سرویس هوش مصنوعی
   - تنظیمات اولیه

#### 6. تست قابلیت‌ها
1. **تست اتصال**: از بخش «تنظیمات» Connection Status را بررسی کنید
2. **تست ربات**: از تلگرام BotFather یک Bot جدید دریافت کنید
3. **تست AI**: از «AI Test» در داشبورد استفاده کنید
4. **تست کانال**: یک کانال ایجاد کنید و ربات را به آن اضافه کنید
