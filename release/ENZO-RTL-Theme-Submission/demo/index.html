سوال‌های پرتکرار

برای تولید محتوا به چه سرویسی نیاز دارم؟

هر سرویس سازگار با OpenAI: API رسمی OpenAI، OpenRouter یا Groq (برای دسترسی پایدار از هاست‌های ایران توصیه می‌شود). هزینه مصرف AI مستقیماً با سرویس‌دهنده خودتان تسویه می‌شود.

آیا خودش بدون اجازه من پست منتشر می‌کند؟

خیر. گردش کار انزو عمداً بر تأیید انسانی استوار است: خروجی AI پیش‌نویس ذخیره می‌شود و تنها پس از تأیید یا زمان‌بندیِ شما منتشر می‌گردد.

اگر سرور موقع انتشار قطع شود چه می‌شود؟

صف انتشار اتمیک است: هر کار با قفل و TTL اجرا می‌شود و در صورت خطا با فاصله نمایی تا ۵ بار تلاش می‌کند. انتشار تکراری رخ نمی‌دهد.

توکن ربات و کلید API کجا ذخیره می‌شود؟

در دیتابیس سایت خودتان، رمزنگاری‌شده با XChaCha20-Poly1305. در هیچ پاسخ REST، فرم یا لاگی نمایش داده نمی‌شوند (به‌صورت خودکار حذف/ماسک می‌شوند).

کدام پیام‌رسان‌ها پشتیبانی می‌شوند؟

تلگرام، بله، ایتا و روبیکا. پلتفرم را از تنظیمات افزونه انتخاب می‌کنید و هر بار یک پیام‌رسان فعال است. این پیش‌نمایش اتصال واقعی به هیچ‌کدام ندارد. برای استفاده از نسخه اصلی، هاست وردپرس باید دسترسی HTTPS خروجی به API پیام‌رسان انتخابی و سرویس AI داشته باشد.

آیا این صفحه واقعاً محتوا را منتشر می‌کند؟

خیر. این صفحه فقط پیش‌نمایش تعاملی با داده‌های نمونه است. انتشار واقعی پس از نصب افزونه در وردپرس، تنظیم ربات و سرویس AI و تأیید شما انجام می‌شود.

ارسال چند عکس هم ممکن است؟

بله. در نسخه افزونه می‌توانید یک عکس با کپشن یا چند عکس را از کتابخانه رسانه انتخاب کنید؛ چند عکس به صورت آلبوم ارسال می‌شود.

نیازمندی‌ها؟

وردپرس ۶.۵+ (تک‌سایت)، PHP 8.1+ با اکستنشن sodium، MySQL 5.7+ / MariaDB 10.3+.
