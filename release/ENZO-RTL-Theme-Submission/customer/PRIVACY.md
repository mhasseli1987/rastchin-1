# حریم خصوصی و جریان داده — ENZO: AI Telegram Admin

افزونه **هیچ داده‌ای به توسعه‌دهنده ارسال نمی‌کند**؛ هیچ تبلیغ، آمارگیری یا تله‌متری وجود ندارد.

## چه داده‌ای کجا ذخیره می‌شود (فقط سایت خودتان)

| داده | محل ذخیره | محافظت |
| --- | --- | --- |
| توکن ربات تلگرام | دیتابیس سایت شما (options) | رمزنگاری XChaCha20-Poly1305 (AES-سطح libsodium) |
| کلید API سرویس هوش مصنوعی | دیتابیس سایت شما | همان رمزنگاری؛ کلید اختیاری `ENZO_ENCRYPTION_KEY` |
| پیش‌نویس/پست‌ها، صف، کانال‌ها | ۵ جدول اختصاصی `wp_enzo_*` | دسترسی فقط با نقش Administrator |
| لاگ‌ها | دیتابیس سایت شما | مقادیر حساس (توکن/کلید) به‌صورت خودکار redact می‌شوند |

## چه داده‌ای و به کجا ارسال می‌شود

| داده | مقصد | هدف |
| --- | --- | --- |
| متن پست + تصویر (هنگام انتشار) | `api.telegram.org` (Bot API تلگرام) | انتشار در کانال شما |
| متن ورودی/خروجی تولید | آدرس سرویس AI که **خودتان** پیکربندی می‌کنید (OpenAI/OpenRouter/…) | تولید/بازنویسی/ترجمه محتوا |
| توکن ربات | `api.telegram.org` (`getMe`، تست اتصال) | اعتبارسنجی |
| license_key + دامنه + نسخه | سرور RTL-Theme (وقتی endpointها فعال شود) | اعتبارسنجی لایسنس و بررسی آپدیت |

- هرگز محتوای پست‌های شما به هیچ مقصد دیگری جز تلگرام و سرویس AI انتخابی شما نمی‌رود.
- «حذف افزونه» همه جدول‌ها، تنظیمات و secretهای رمزنگاری‌شده را کامل پاک می‌کند (تست‌شده).
- مسئولیت نگهداری داده‌ها و رعایت قوانین محتوای ارسالی، بر عهده مدیر سایت است.

## داده‌های سرویس AI
مصرف و نگهداری داده توسط سرویس AI تابع قوانین همان سرویس‌دهنده است (Policy شرکت مربوطه). افزونه فقط واسط است.
