## ۴ اسکریپت ویدیو (۶۰-۹۰ ثانیه، دمو الزامی ماده ۷-۹)
1. **`video-1-intro` — معرفی (۶۰s):** مشکل (انتشار دستی) ← راه‌حل آتا ← ۳ قابلیت کلیدی ← فراخوان CTA.
2. **`video-2-setup` — راه‌اندازی (۹۰s):** نصب افزونه ← BotFather و توکن ← اتصال در پنل ← ادمین‌کردن ربات در کانال.
3. **`video-3-ai` — تولید محتوا (۹۰s):** پیکربندی AI ← وارد کردن موضوع ← خروجی AI ← بازبینی و اصلاح.
4. **`video-4-publish` — انتشار (۶۰s):** تأیید انسانی ← زمان‌بندی ← مشاهده انتشار خودکار در کانال ← لغو/retry.

هر ویدیو: نریشن فارسی، زیرنویس فارسی، رزولوشن 1920×1080، هویت بصری یکسان (رنگ برند آتا، فونت فارسی یکسان).
